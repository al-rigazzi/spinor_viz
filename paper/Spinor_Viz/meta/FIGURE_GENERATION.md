# Figure Generation Guide for Spinor Visualization Paper

This document explains how to generate the figures for the spinor visualization paper using the Python `spinor_viz` package.

## Prerequisites

- Python 3.9+
- The `spinor_viz` package installed in development mode (`pip install -e .` from the repository root)
- Dependencies: NumPy, Matplotlib, Plotly

## Output Directory

All figures are generated to `paper/Spinor_Viz/viz_figures/` with a `_py` suffix.

---

## Generation Script

All paper figures are generated by a single Python script:

**Script:** `paper/Spinor_Viz/meta/generate_figures_py.py`

**Run command:**
```bash
cd /path/to/spinor_viz
python paper/Spinor_Viz/meta/generate_figures_py.py
```

This generates all figures at once. Individual generation functions can also be called from Python:

```python
from paper.Spinor_Viz.meta.generate_figures_py import (
    generate_planar_chords,
    generate_hyperchords_3d,
    generate_spinor_2d,
    generate_anim_3d,
    generate_anim_2d,
)
```

---

## Figure 1: Planar Chords (Two panels)

**Function:** `generate_planar_chords()`

**Description:** Generates two panels showing the planar half-angle chord construction. One panel shows general angle θ, the other shows θ + π.

**Output files:**
- `planar_chords_theta_py.png`
- `planar_chords_theta_pi_py.png`

**Key features:**
- Uses `plot_planar_chord_panel()` from `spinor_viz.visualization`
- Blue arrows for the cos(θ/2) chord, red arrows for the sin(θ/2) chord
- Solid arrows for positive values, dashed with filled circles for negative

---

## Figure 2: 3D Hyperchords Schematic

**Function:** `generate_hyperchords_3d()`

**Description:** Generates a 3D schematic of the hyperchord construction showing the sphere, equator, and two hyperchord circles meeting at the shared point Q.

**Output file:** `hyperchords_3d_py.png`

**Key features:**
- Uses `plot_spinor_3d()` from `spinor_viz.visualization`
- Colorblind-friendly Wong palette:
  - Teal/bluish-green (`#009E73`) for upper hyperchord (thicker line, linewidth 3.0)
  - Orange (`#E69F00`) for lower hyperchord (thinner line, linewidth 1.5)
  - Upward triangle (▲) marker for upper equator contact point
  - Downward triangle (▼) marker for lower equator contact point
- Spinor: θ = π/3, φ = π/4
- View angles: (25, 15)

---

## Figure 3: 2D Projections (2 panels)

**Function:** `generate_spinor_2d()`

**Description:** Generates 2D projections of the hyperchord visualization in both circle and ellipse modes.

**Output files:**
- `spinor2d_circles_py.png` — Circle mode (preserves true hyperchord radii)
- `spinor2d_ellipses_py.png` — Ellipse mode (true orthogonal projection)

---

## Figure 4: Z-Rotation Animation (3D, 8 frames)

**Function:** `generate_anim_3d()`

**Description:** Generates 8 frames showing spinor evolution under z-axis rotation from ω = 0 to ω = 7π/2.

**Output files:** `anim_z_01_py.png` through `anim_z_08_py.png`

**Parameters:**
- Initial state: θ = π/3, φ = π/4
- Rotation operator: exp(-iωσ_z/2)
- 8 frames at ω = 0, π/2, π, 3π/2, 2π, 5π/2, 3π, 7π/2

## Core Visualization Functions

### `plot_spinor_3d()`
Main 3D visualization function from `spinor_viz.visualization`.

**Usage:**
```python
from spinor_viz import Spinor, plot_spinor_3d
import numpy as np

s = Spinor.from_angles(theta=np.pi/3, phi=np.pi/4)
ax = plot_spinor_3d(s, view_angles=(25, 15))
```

### `plot_spinor_2d()`
2D projection visualization from `spinor_viz.visualization`.

**Usage:**
```python
from spinor_viz import Spinor, plot_spinor_2d

ax = plot_spinor_2d(s, show_ellipses=True, show_circles=False)
```

### `plot_planar_chord_panel()`
Planar chord construction panel from `spinor_viz.visualization`.

### `create_interactive_3d()`
Interactive 3D Plotly visualization from `spinor_viz.visualization`.

## Color Conventions (Wong Colorblind-Friendly Palette)

| Element                | Color            | Hex code    |
|------------------------|------------------|-------------|
| Upper hyperchord c↑    | Teal/bluish-green| `#009E73`   |
| Lower hyperchord c↓    | Orange           | `#E69F00`   |
| Real part arrows       | Blue             | `#0072B2`   |
| Imaginary part arrows  | Vermillion       | `#D55E00`   |
| Bloch vector           | Reddish-purple   | `#CC79A7`   |

## Line Width Conventions

| Element             | Linewidth |
|---------------------|-----------|
| Upper hyperchord c↑ | 3.0       |
| Lower hyperchord c↓ | 1.5       |

## Marker Conventions

| Element                           | Marker           |
|-----------------------------------|------------------|
| Upper equator contact point P↑    | ▲ (upward triangle)  |
| Lower equator contact point P↓   | ▼ (downward triangle)|
| Shared point Q                    | ● (filled circle)    |

## Arrow Conventions

- **Solid arrow with arrowhead** = positive value
- **Dashed arrow with filled circle** = negative value
- Real part arrows have end markers; imaginary part arrows do not
